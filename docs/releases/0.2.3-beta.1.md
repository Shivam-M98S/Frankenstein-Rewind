## 0.2.3 beta 1

This preview focuses on Spotify, local music, and the classic click wheel.

- Browse Spotify playlists and Liked Songs under **Music → Spotify**. Browser sign-in saves authorization securely and refreshes it when possible.
- Control playback through the Spotify Android app. If the native connection is unavailable, Rewind can use an active Spotify Connect device with an eligible Premium account.
- Now Playing follows the selected music source when switching from Spotify to local files.
- Home and Library Settings are simpler. Radio and home-server setup are hidden for this preview.

### Install on Android

1. Download **Frankenstein-Rewind-0.2.3-beta.1.apk** from the release assets and open it on your phone.
2. If Android asks, allow your browser or Files app to install apps from this source. Tap **Update** over the 0.2.2 preview, or **Install** for a fresh installation.
3. Sign in to Spotify on the phone. In Rewind, open **Settings → Library → Spotify setup**. Keep your saved public client ID or enter it on a fresh install. Choose **Allow library access**, finish browser sign-in, then choose **Connect playback**.
4. Open **Music → Spotify → Playlists** and select a playlist. If Rewind asks for an active device, start a song in Spotify on the phone and retry.

The signed 0.2.2 and 0.2.3 previews share the same package, certificate, and Spotify callback. Existing preview registrations carry over. Nine automated tests passed. Phone testing of sign-in, track transitions, and reconnection is still open.
